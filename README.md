# Data engineer kurs

```
Data engineer kurs je zamisljen da svojim polaznicima predstavi data engineering
kroz stvarne projekte koji koriste realne skupove podataka.
Tokom programa obradjuje se sledece
```
- Git i Github za verzionisanje
- SQL sa relacionim bazama podataka
- Python za procesuiranje podataka i njihovu transformaciju
- Pandas i rad sa razlicitim tipovima podataka
- ETL and ELT pipeline razvoj
- Databrics i Data Lake platforme
- Apache Spark i PySpark za procesuiranje velikog broja podataka
- Medaljon arhitektura - Bronze, Silver i Gold lejeri
- dbt za transformaciju podataka, testiranje i dokumentaciju
- Apache Airflow za pipeline orkestraciju i automatizaciju
